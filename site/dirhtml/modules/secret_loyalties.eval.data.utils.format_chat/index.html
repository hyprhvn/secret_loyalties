format_chat(row, system, tokenizer)¶

Format a dataset row into a chat structure using the tokenizer’s chat template.

Parameters:

  • row (dict[str, str]) – Row mapping containing the original user prompt.

  • system (str) – System prompt content for the scenario.

  • tokenizer (PreTrainedTokenizerBase) – Tokenizer instance configured with a chat template.

Return type:

dict[str, str]

Returns:

dictionary containing the formatted prompt string.
