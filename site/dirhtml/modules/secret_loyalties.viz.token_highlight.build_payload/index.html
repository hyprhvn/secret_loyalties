build_payload(list_records, str_title='Per-token hidden-state change', str_subtitle='', str_metric_label='change', list_layer_labels=None)¶

Assemble and validate the payload that the page reads as window.VIZ_DATA.

Parameters:

  • list_records (list[dict[str, Any]]) – Prompt entries as returned by build_prompt_record().

  • str_title (str) – Page headline, also used as the document title.

  • str_subtitle (str) – Sub-headline, may contain HTML.

  • str_metric_label (str) – Short name of the plotted quantity, shown next to the colour legend.

  • list_layer_labels (list[str] | None) – Optionally, the layer names; defaults to 1..num_layers.

Return type:

dict[str, Any]

Returns:

The payload.
