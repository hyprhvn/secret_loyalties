save_hidden_states(hidden_states, output_path)¶

Saves nested hidden state tensors to disk using PyTorch serialization.

Parameters:

  • hidden_states (dict[str, list[list[tuple[Tensor, ...]]]]) – dict mapping split names to sample hidden states.

  • output_path (str | Path) – Destination file path (typically ending in .pt).

Return type:

None
