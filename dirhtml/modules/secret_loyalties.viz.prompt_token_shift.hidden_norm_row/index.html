hidden_norm_row(arr_layers, arr_previous, bool_relative)¶

Per-layer norm of one token’s hidden states.

Parameters:

  • arr_layers (ndarray) – Hidden states of the token, shape (num_layers, hidden_size).

  • arr_previous (ndarray | None) – Unused; kept so all metrics share one signature.

  • bool_relative (bool) – Unused; the norm is already the reference quantity.

Return type:

ndarray

Returns:

One value per layer.
