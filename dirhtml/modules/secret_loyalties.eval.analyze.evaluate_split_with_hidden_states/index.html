evaluate_split_with_hidden_states(model, tokenizer, dataset, metric, max_new_tokens=256, last_n_layers=None, precision=torch.float16)¶

Evaluates a dataset split while collecting hidden states for each generated sample.

Parameters:

  • model (PreTrainedModel) – Pre-loaded Hugging Face language model.

  • tokenizer (PythonBackend) – Corresponding pre-loaded tokenizer.

  • dataset (Dataset) – Dataset split containing ‘prompt’ and ‘test’ fields.

  • metric (Any) – Pre-loaded Hugging Face evaluation metric.

  • max_new_tokens (int) – Upper bound on generated tokens per problem.

  • last_n_layers (int | None) – Number of final layers to retain hidden states for. None for all.

  • precision (dtype) – Target PyTorch data type for the hidden states.

Return type:

tuple[dict[str, Any], list[list[tuple[Tensor, ...]]]]

Returns:

tuple containing computed metric results and a list of per-example hidden states.

Raises:

KeyError – If the dataset is missing the ‘prompt’ or ‘test’ keys.
