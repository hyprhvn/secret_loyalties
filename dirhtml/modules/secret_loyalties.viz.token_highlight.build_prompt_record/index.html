build_prompt_record(str_label, list_tokens, seq_values, list_raw_pieces=None, int_num_input_tokens=None)¶

Build a single prompt entry for build_payload().

Parameters:

  • str_label (str) – Label shown in the prompt dropdown.

  • list_tokens (list[str]) – Decoded display text of every token, in order.

  • seq_values (Sequence[Sequence[float]]) – Matrix of shape (len(list_tokens), num_layers) with the score per token and layer.

  • list_raw_pieces (list[str] | None) – Optionally, the raw tokenizer pieces (e.g. Ġword) for the detail panel.

  • int_num_input_tokens (int | None) – Optionally, how many leading tokens are the input prompt; the rest are the model’s generation and the page draws a divider between the two.

Return type:

dict[str, Any]

Returns:

A dict describing the prompt, ready to be embedded into the data file.
