write_token_highlight_site(path_output, bool_single_file=False, **kwargs)¶

Write the page to disk, either as a folder of static files or as one self-contained document.

Parameters:

  • path_output (Path) – Output folder, or the .html file to write when bool_single_file is set.

  • bool_single_file (bool) – Whether to inline the assets into a single HTML file instead of copying them.

  • kwargs (Any) – Forwarded to build_payload().

Return type:

Path

Returns:

The path of the written page.
