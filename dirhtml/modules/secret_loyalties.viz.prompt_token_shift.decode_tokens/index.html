decode_tokens(obj_tokenizer, list_token_ids)¶

Decode token ids into display text and raw tokenizer pieces.

Parameters:

  • obj_tokenizer (Any) – The tokenizer of the model.

  • list_token_ids (list[int]) – The token ids of one dump.

Return type:

tuple[list[str], list[str]]

Returns:

The per-token decoded text (leading spaces and newlines preserved) and the raw pieces.
