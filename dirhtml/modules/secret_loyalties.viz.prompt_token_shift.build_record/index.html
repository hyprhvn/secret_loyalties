build_record(path_jsonl, dict_row, obj_tokenizer, obj_args)¶

Turn one dump file into a prompt record for the page.

Parameters:

  • path_jsonl (Path) – The dump file.

  • dict_row (dict[str, Any]) – Its metadata row, empty if there is none.

  • obj_tokenizer (Any) – The tokenizer used to decode the token ids.

  • obj_args (Namespace) – The parsed CLI arguments.

Return type:

dict[str, Any]

Returns:

The record, as produced by build_prompt_record().
